# واجهة تكنو شام (Next.js 14)

الموقع العام + لوحة التحكم، مبنيّان بـ Next.js (App Router) و TypeScript.

## التشغيل محلياً

```bash
cd frontend
npm install
cp .env.local.example .env.local     # وعدّل الرابط إن لزم
npm run dev                          # http://localhost:3000
```

> تأكّد أن خلفية Django تعمل على `http://localhost:8000` (انظر `../backend/README.md`).

## الصفحات

- `/` — الموقع العام (يُبنى من الـ API، مع بيانات افتراضية احتياطية إن كان الخادم متوقفاً).
- `/dashboard/login` — تسجيل الدخول (المشرف الافتراضي: `admin` / `admin12345`).
- `/dashboard` — نظرة عامة على كل المواقع المرتبطة.
- `/dashboard/projects` — إدارة المشاريع.
- `/dashboard/sites` — ربط مواقعك الأخرى ومتابعة إحصائياتها.
- `/dashboard/messages` — رسائل التواصل.

## زر «المظهر» 🎨

في أعلى لوحة التحكم زر **المظهر** يفتح سايدبار لتغيير:
الألوان (مع قوالب جاهزة)، الخط، حجم الخط، استدارة الحواف، والوضع الداكن —
مع **معاينة حيّة** فورية، ثم حفظ يُطبّق التغييرات على الموقع العام.

## البناء والنشر

```bash
npm run build && npm start
```

للنشر على Vercel: اربط المستودع، واضبط متغيّر البيئة
`NEXT_PUBLIC_API_URL` على رابط خادم Django في الإنتاج.
